# forum-pars

Архив веток астрономического форума astronomy.ru для офлайн-чтения и анализа.

## Как запустить

Одна кнопка для двух сценариев — скрипт сам понимает что делать.

1. **Actions** → **Parse Forum Thread** → **Run workflow**
2. Заполнить:
   - **URL ветки** — обязательно
   - **Имя ветки** — заполнять ТОЛЬКО для НОВОЙ ветки
3. **Run workflow** → подождать 15-60 минут → готово

### Новая ветка

Заполняешь оба поля:
- URL: `https://astronomy.ru/forum/index.php/topic,185615.0.html`
- Имя: `onstep`

Скрипт скачивает с нуля → создаёт `threads/onstep.txt` → записывает в `threads/_index.json`.

### Обновление существующей

Заполняешь **только URL**, имя оставляешь пустым:
- URL: `https://astronomy.ru/forum/index.php/topic,185615.0.html`
- Имя: (пусто)

Скрипт находит ветку в индексе по TOPIC_ID, скачивает только новые страницы (с перекрытием -1 страница для надёжности), дописывает в `threads/onstep.txt` после маркера обновления.

### Что произойдёт если...

| Ситуация | Поведение |
|---|---|
| Запустила без имени, ветки нет в индексе | Ошибка: "введи имя" |
| Запустила с именем, ветка уже есть | Имя игнорируется, идёт обновление |
| Запустила с именем, которое уже занято другой веткой | Ошибка: "имя занято" |
| Запустила обновление, новых постов нет | Файл не меняется, коммита не будет |

## Получить ссылку для Claude

Открыть `threads/<имя>.txt` → **Raw** → копировать URL.

```
https://raw.githubusercontent.com/USERNAME/forum-archive/main/threads/onstep.txt
```

## Структура файлов

- `parse_thread.py` — скрипт скачивания/обновления
- `.github/workflows/parse-thread.yml` — workflow
- `threads/<имя>.txt` — текстовые архивы веток
- `threads/_index.json` — реестр всех веток (TOPIC_ID, имя, URL, last_offset, число постов, дата)

## Технические детали

- **Задержка между запросами:** 10 секунд
- **MAX_OFFSET** определяется автоматически по навигации первой страницы
- **При обновлении** перекачивается последняя запомненная страница + всё после неё (страховка от редактирования постов)
- **Дедупликация по msg_id** при склейке старого и нового
- **Маркер обновления** в текстовом файле: `=== ОБНОВЛЕНИЕ DD.MM.YYYY: добавлено N постов ===`
